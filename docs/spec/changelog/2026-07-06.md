# Changelog: week of 2026-07-06 (Mon) – 2026-07-12 (Sun)

Feature additions and fixes recorded during this week.

## TeXForm: Rule and RuleDelayed render as arrows (2026-07-06)

`Rule[a, b]` and `RuleDelayed[a, b]` previously fell through to the generic
function-call rendering in `TeXForm` (`Rule[x, 2]`) instead of the arrow
notation Mathematica uses. `src/print_latex.c` now special-cases both heads:

- `Rule[a, b]` → `a \to b`
- `RuleDelayed[a, b]` → `a \Rightarrow b`

This matches the arrow rendering `Limit` already produces for its `x -> x0`
argument, and fixes lists of rules (e.g. `Solve` output) rendering with
readable arrows instead of raw `Rule[...]` calls in the notebook frontend.
