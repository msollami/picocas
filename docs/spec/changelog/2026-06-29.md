## Graph subsystem: construction, normalization & printing (2026-07-01)

Phase 1 makes `Graph[...]` a real value.

- **`Graph`** (`src/graph/construct.c`) — normalizes edge sugar
  (`Rule`/`->` → `DirectedEdge`, `TwoWayRule`/`<->` → `UndirectedEdge`; existing
  `DirectedEdge`/`UndirectedEdge` pass through), derives vertices in
  first-appearance order for `Graph[edges]`, validates, and returns the
  canonical `Graph[List, List]`. Malformed input (self-loops, parallel edges,
  3-arg edges, unknown endpoints) is left unevaluated; anti-parallel directed
  edges are allowed. Reaches a fixed point (returns `NULL` when already
  canonical).
- **`GraphQ`** (`src/graph/graphq.c`) — validity predicate over the shared
  `graph_is_valid` helper (`src/graph/graph_util.c`).
- **Parser** — added `<->` → `TwoWayRule[u, v]` (precedence 120, like `Rule`),
  matched ahead of `<>`/`<=`/`<`.
- **Printer** — `DirectedEdge`/`UndirectedEdge` print infix as `u -> v` /
  `u <-> v` (round-trippable); a graph shows the terse summary
  `Graph[<n vertices, m edges>]` in standard output, with `InputForm`/`FullForm`
  printing the literal constructor.
- Tests: `tests/test_graph.c` (edge-sugar normalization, vertex derivation,
  summary printing, `GraphQ` truth table, malformed-input rejection, InputForm
  round-trip). Both builtins carry `ATTR_PROTECTED` and docstrings.

## Graph subsystem: generators (2026-07-01)

Phase 4 adds standard constructors (`src/graph/generators.c`, all
`ATTR_PROTECTED`, with docstrings): `CompleteGraph[n]`, `CycleGraph[n]`,

## Graphs: distinct kernels for the advanced embeddings (2026-07-02)

`GravityEmbedding`, `HighDimensionalEmbedding`, and `HyperbolicSpringEmbedding`
previously all aliased to the plain Fruchterman–Reingold spring kernel, so they
rendered identically. Each now has its own kernel in `src/graph/layout.c`:
- **Gravity** — FR plus a central gravity well (pull ∝ distance × (1+degree)),
  drawing hubs inward and compacting the layout.
- **HighDimensional** / **Spectral** — pivot-MDS: BFS distances to two far-apart
  pivots (double-sweep) used as the 2D coordinates, laying the graph out along
  its diameter.
- **HyperbolicSpring** / **Spherical** — the spring layout followed by a radial
  warp (`r → r^0.45`) crowding vertices toward a disk boundary.
All remain fully deterministic. Verified pairwise-distinct against
`SpringElectricalEmbedding` and `RadialEmbedding`; the gallery's Layouts
notebook now demos all five.

## BipartiteGraphQ (2026-07-02)

## Graph distance metrics (2026-07-02)

Added `VertexEccentricity`, `GraphDiameter`, `GraphRadius`, `GraphCenter`
(`src/graph/metrics.c`) — a cohesive family over one BFS-per-vertex helper
(`O(V·(V+E))`) on the shared integer adjacency. Eccentricity is the greatest
shortest-path distance from a vertex (`Infinity` if any vertex is unreachable —
possible per-vertex on directed graphs); diameter = max eccentricity, radius =
min finite eccentricity, center = vertices attaining the radius. Directed graphs
follow edge direction; disconnected graphs give `Infinity`/`{}`. All
`ATTR_PROTECTED` with docstrings; tests in `tests/test_graph.c` (path, cycle,
complete, disconnected, directed out-star, single vertex). Second addition from
the missing-Wolfram-graph-functionality sweep.

## AcyclicGraphQ + TopologicalSort (2026-07-02)

Added `AcyclicGraphQ[g]` and `TopologicalSort[g]` (`src/graph/acyclic.c`), both
on Kahn's algorithm over the shared integer adjacency (`O(V+E)`).
`TopologicalSort` returns a forward-pointing vertex order for a DAG, else
`$Failed` (undirected edges act as 2-cycles → `$Failed`), matching Wolfram's
directed-only semantics. `AcyclicGraphQ` is `True` iff there is no cycle: for an
all-directed graph, Kahn removes every vertex (DAG); for a graph with undirected
edges, the underlying undirected graph is a forest (`E = V − #components`).
`ATTR_PROTECTED` + docstrings; tests in `tests/test_graph.c` (DAG, directed
cycle, 2-cycle, undirected tree/forest/cycle, edgeless, non-graph). Third
addition from the missing-Wolfram-graph-functionality sweep.

## GraphComplement (2026-07-02)

Added `GraphComplement[g]` (`src/graph/complement.c`) — the graph on the same
vertices whose edges are exactly the non-edges of `g`, built from an `n x n`
membership matrix (`O(V^2)`, the natural cost of a dense complement). Undirected
graphs give an undirected complement (edgeless → complete `K_n`, complete →
edgeless), directed graphs stay directed (all ordered non-self pairs minus the
present edges), and applying it twice restores the original edge set. Returns
the canonical `Graph` value directly. `ATTR_PROTECTED` + docstring; tests in
`tests/test_graph.c` (path, edgeless↔complete, cycle, double-complement,
directed, validity, non-graph). Fourth addition from the missing-Wolfram-graph
sweep.

## KirchhoffMatrix (2026-07-02)

Added `KirchhoffMatrix[g]` (`src/graph/kirchhoff.c`) — the graph Laplacian
`L = D - A` (degree diagonal minus adjacency), an ordinary `List`-of-`List`s
matrix built from the shared adjacency (`O(V^2)`). Every row sums to 0. It is
the bridge to spectral graph theory via the existing dense linear algebra:
`Eigenvalues[KirchhoffMatrix[g]]` exposes the algebraic connectivity and the
zero-eigenvalue multiplicity (= #components), and any cofactor `Det` gives the
spanning-tree count (Matrix-Tree). `ATTR_PROTECTED` + docstring; tests in
`tests/test_graph.c` (exact P3/C3/K4 Laplacians, zero row sums, trace = 2|E|,
and eigenvalue interop). Fifth addition from the missing-Wolfram-graph sweep.

## EdgeConnectivity (2026-07-02)

Added `EdgeConnectivity[g]` (`src/graph/edgeconnectivity.c`) — the minimum number
of edges whose removal disconnects `g` (companion to `VertexConnectivity`). By
max-flow/min-cut, the minimum s-t edge cut is the max s-t flow with unit
capacities; global edge connectivity fixes one source over all targets
(undirected) or scans all ordered pairs (directed). Each flow is Edmonds-Karp
(BFS-augmenting). Returns 0 for a disconnected / not-strongly-connected graph.
`ATTR_PROTECTED` + docstring; tests in `tests/test_graph.c` (complete, cycle,
path, star, bridge, disconnected, directed cycle vs path, non-graph). Sixth
addition from the missing-Wolfram-graph sweep.

## EulerianGraphQ (2026-07-02)

Added `EulerianGraphQ[g]` (`src/graph/eulerianq.c`) — `True` iff `g` has an

## ClosenessCentrality (2026-07-02)

## TransitiveClosure (2026-07-02)

## BetweennessCentrality (2026-07-02)

Added `BetweennessCentrality[g]` (`src/graph/betweenness.c`) — for each vertex,
the number of shortest paths through it, `sum sigma_sv*sigma_vt/sigma_st` over
pairs on a shortest path. All-pairs distances and shortest-path counts come from
one BFS per source (Brandes-style counting), then an O(V^3) accumulation.
Undirected pairs are counted once (ordered sum halved), directed keeps the
ordered sum; distances follow direction. Exact rationals — the per-vertex sum is
reduced by the evaluator, so tied paths give clean fractions (every C4 vertex is
`1/2`). `ATTR_PROTECTED` + docstring; tests in `tests/test_graph.c` (path formula
0/3/4/3/0, complete all 0, star center 6, C4 halves, directed, edgeless).
Fourteenth addition from the missing-Wolfram-graph sweep.

## FindEulerianCycle (2026-07-03)

Added `FindEulerianCycle[g]` (`src/graph/findeuler.c`) — the constructive
companion to `EulerianGraphQ`. Returns an Eulerian cycle as a vertex list
`{v0, …, v0}` (a closed walk traversing every edge exactly once), or `{}` when
none exists. Hierholzer's algorithm, `O(V+E)`: walk unused edges onto a stack,
splice in sub-tours at dead ends, and read the reversed pop-order as the tour.
Acceptance requires both that all `ne` edges were consumed *and* that the walk is
closed (returns to its start) — so a graph with an Eulerian *path* but no cycle
(`PathGraph[3]`, a directed open path, `CompleteGraph[4]`'s four odd vertices)
correctly yields `{}` rather than an open trail. Handles directed (follow
out-edges) and undirected (each edge walkable once from either end) graphs;
undirected edges share one id across both incidence lists so they are never
reused. `ATTR_PROTECTED` + docstring; tests in `tests/test_graph.c` (C3 exact
tour, C4/K5 lengths, closed-endpoints check, directed cycle, and the non-Eulerian
path/odd-degree/disconnected/open-directed/edgeless cases → `{}`). Fifteenth
addition from the missing-Wolfram-graph sweep.

## FindHamiltonianCycle (2026-07-03)

Added `FindHamiltonianCycle[g]` (`src/graph/findhamilton.c`) — the constructive
Hamiltonian companion to `FindEulerianCycle`. Returns a Hamiltonian cycle as a
vertex list `{v0, …, v0}` (a closed walk visiting every vertex exactly once), or
`{}` when none exists. Depth-first backtracking over `GraphAdj.out[]` with a
visited set; the search is rooted at the first vertex (WLOG — a Hamiltonian
cycle passes through every vertex), so results are deterministic. Cheap
necessary-condition prunes short-circuit the trivially impossible: fewer than 3
vertices, or any vertex missing an out- or in-neighbour, returns `{}` before any
search. `out[]` already encodes edge direction (an undirected edge sits in both
endpoints' `out[]`), so directed and undirected graphs share one code path, and
the simple-graph invariant (no self-loops/parallel edges) means a distinct-vertex
cycle of length ≥ 3 is automatically a distinct-edge cycle — no per-edge
bookkeeping. Exponential worst case, instant on gallery-sized graphs.
`ATTR_PROTECTED` + docstring; tests in `tests/test_graph.c` (C3 exact tour,
C5/K4/W5 lengths, all-vertices-covered, closed endpoints, directed cycle, and the
non-Hamiltonian path/star/n<3/edgeless/disconnected/broken-directed cases →
`{}`). Sixteenth addition from the missing-Wolfram-graph sweep.

## EdgeBetweennessCentrality (2026-07-03)

Added `EdgeBetweennessCentrality[g]` (`src/graph/edgebetweenness.c`) — for each
edge, the number of shortest paths that run along it, summed over all vertex
pairs; the edge analogue of `BetweennessCentrality` and the score peeled by
Girvan–Newman community detection. The number of shortest `s→t` paths using
directed edge `a→b` is `σ_sa·σ_bt` when `d(s,a)+1+d(b,t)=d(s,t)`, so

the per-edge sum is reduced by the evaluator, giving exact rationals. `O(E·V²)`.

edgeless, directed path, length = edge count, non-graph unevaluated).
Eighty-fourth addition from the missing-Wolfram-graph sweep.

## GraphAssortativity (2026-07-03)

Added `GraphAssortativity[g]` (`src/graph/graphassortativity.c`) — the degree
assortativity coefficient: the Pearson correlation between the degrees of the two
endpoints of an edge, an **exact rational** in `[−1, 1]`. Newman's edge-list form
reduces to a ratio of integers: over the `M` undirected edges with endpoint
degrees `j, k`, let `A = Σ j·k`, `S₁ = Σ (j+k)`, `S_q = Σ (j²+k²)`; then

positive factor and is 0 exactly when the graph is regular (or edgeless), giving
`Indeterminate`. Edge direction ignored (underlying undirected graph). A star is
perfectly disassortative (`−1`), `PathGraph[4]` is `−1/2`. `ATTR_PROTECTED` +
docstring; tests in `tests/test_graph.c` (star = −1, P4 = −1/2, cycle/complete/
edgeless/directed-cycle = Indeterminate, range check, non-graph unevaluated).
Seventy-fourth addition from the missing-Wolfram-graph sweep.

## CompleteKaryTree (2026-07-03)

Added `CompleteKaryTree[L]` / `CompleteKaryTree[L, k]` (`src/graph/completekarytree.c`)
— the complete k-ary tree with `L` levels (`k = 2` by default): a root whose every

## TuranGraph (2026-07-03)

Added `TuranGraph[n, r]` (`src/graph/turangraph.c`) — the Turán graph `T(n, r)`,
the complete `r`-partite graph on `n` vertices whose parts are as equal as
possible: vertex `i` (0-based) goes in part `i mod r`, and vertices in different
parts are joined. By Turán's theorem it is the `n`-vertex graph with the most
edges that is free of an `(r+1)`-clique. `O(n²)`; `T(n,1)` is edgeless,

`BipartiteGraphQ` and `ChromaticNumber`; bad args unevaluated). Fifty-second
addition from the missing-Wolfram-graph sweep.

## GraphProduct (2026-07-03)

Added `GraphProduct[g1, g2, type]` (`src/graph/graphproduct.c`) — a product graph
on the vertex set `V1 × V2` (product vertices are the pairs `{a, b}`), undirected,

## GraphJoin (2026-07-03)

Added `GraphJoin[g1, g2]` (`src/graph/graphjoin.c`) — the graph join: the vertices
are the disjoint union of `g1`'s and `g2`'s relabelled `1..n1+n2` (`g1`'s block

missing-Wolfram-graph sweep.

## KatzCentrality (2026-07-03)

Added `KatzCentrality[g, alpha]` (`src/graph/katzcentrality.c`) — the Katz
centrality of each vertex with attenuation `alpha` and base weight `1`: a vertex
is central if pointed to by central vertices, with a length-`k` walk discounted
by `alpha^k`. It satisfies `x_i = alpha·Σ_{j→i} x_j + 1`, i.e.
`(I − alpha·Aᵀ) x = 1`, which is assembled and solved exactly via `LinearSolve`,
so a rational `alpha` yields an exact rational vector (K2 at `1/10` → `{10/9,
10/9}`, P3 → `{55/49, 60/49, 55/49}`). Uses in-edges (`Aᵀ`), so a directed
vertex's score reflects who points at it; `alpha = 0` gives all `1`. Reuses the
same exact-linear-system approach as `PageRankCentrality`. Left unevaluated for a
non-numeric `alpha`, wrong arity, or a singular `I − alpha·Aᵀ` (alpha at a
reciprocal eigenvalue). `O(V³)`. `ATTR_PROTECTED` + docstring; tests in
`tests/test_graph.c` (alpha=0 base, edgeless, single vertex, exact K2/C4/P3
rationals, directed in-edge boost, non-numeric/non-graph/arity unevaluated).
Forty-sixth addition from the missing-Wolfram-graph sweep.

## PageRankCentrality (2026-07-03)

Added `PageRankCentrality[g]` (`src/graph/pagerank.c`) — the PageRank of each
vertex (random surfer with damping `d = 17/20`), returned as an **exact rational**
probability vector summing to 1. Instead of iterating to a floating-point fixed
point, it solves the defining linear system `(I − dM)π = (1−d)/n·1` exactly, where
`M` is the column-stochastic transition matrix (`M[v][u] = 1/outdeg(u)` for
`u→v`, and `1/n` for a dangling `u` that teleports everywhere). The rational
matrix and right-hand side are assembled in C and handed to the existing exact
`LinearSolve`, so the whole result is reduced rationals — regular and
all-dangling graphs give the uniform `1/n`, a star's centre outranks its leaves
(`{71/148, 77/444, ...}`), and a directed hub gives `{20/77, 57/154, 57/154}`.
Edge direction followed; `(I − dM)` is invertible since `M` is column-stochastic
and `d < 1`. `O(V³)` from the solve. `ATTR_PROTECTED` + docstring; tests in
`tests/test_graph.c` (sum = 1, uniform on C4/K5/edgeless/directed-cycle, single
vertex, exact star/hub rationals, centre > leaf). Forty-fifth addition from the
missing-Wolfram-graph sweep.

## VertexContract (2026-07-03)

Added `VertexContract[g, {v1, v2, ...}]` (`src/graph/vertexcontract.c`) — merges
the listed vertices into a single vertex (the first of the list), redirecting
every incident edge to the representative, deleting the resulting self-loops, and
collapsing parallel edges with edge-kind-aware, symmetric-for-undirected
equality. The representative keeps its position; the other listed vertices are
removed. Contracting an edge's two endpoints realises edge contraction (a triangle
becomes a single edge; a path's endpoints close it into a cycle), and contracting
all vertices leaves one isolated vertex. Direction-aware, returns a canonical
`Graph`. `ATTR_PROTECTED` + docstring; tests in `tests/test_graph.c` (triangle→edge,
singleton no-op, path-ends→triangle, contract-all→singleton, parallel dedup,
directed self-loop drop, validity, bad-vertex/non-graph unevaluated). Forty-fourth
addition from the missing-Wolfram-graph sweep.

## PathGraphQ (2026-07-03)

Added `PathGraphQ[g]` (`src/graph/pathgraphq.c`) — `True` iff `g` is a path graph:

sweep.

## ReverseGraph (2026-07-03)

Added `ReverseGraph[g]` (`src/graph/graphreverse.c`) — `g` with the direction of
every edge reversed: a `DirectedEdge[a, b]` becomes `DirectedEdge[b, a]`, an

predecessors (out-degree ↔ in-degree, reachability ↔ reverse reachability), is an

undirected graphs. `O(V+E)`, returns a canonical `Graph`. `ATTR_PROTECTED` +
docstring; tests in `tests/test_graph.c` (edge reversal, vertices/count
preserved, undirected unchanged, involution, in/out-degree swap, reversed

the missing-Wolfram-graph sweep.
